# Worldbuilding and reference data

[Sidebar.tsx](../../app/src/renderer/src/components/layout/Sidebar.tsx) and [EntityTree.tsx](../../app/src/renderer/src/components/world/EntityTree.tsx) expose book-scoped records and ordering. The book workspace loads entity rows via IPC. [EditorView](../../app/src/renderer/src/pages/workspace/EditorView.tsx) switches to the active editor. The common palette and editable sheet styles are in [index.css](../../app/src/renderer/src/index.css).

| Area | Main source and behavior |
| --- | --- |
| Characters | [CharacterManager](../../app/src/renderer/src/components/world/CharacterManager.tsx) stores identity, appearance, personality, goals, relationships and notes through [characters IPC](../../app/src/main/ipc/characters.ts). Portrait actions use image storage. [VoiceIntelligenceTab](../../app/src/renderer/src/components/world/VoiceIntelligenceTab.tsx) works with voice profile, patterns and dialogue samples. |
| Locations | [LocationManager](../../app/src/renderer/src/components/world/LocationManager.tsx) edits geography, culture, history and notes through [locations IPC](../../app/src/main/ipc/locations.ts). [LocationSummaryPanel](../../app/src/renderer/src/components/world/LocationSummaryPanel.tsx) gathers linked chapter evidence and optional AI summaries. [locationSummary.ts](../../app/src/renderer/src/services/locationSummary.ts) derives a cache key and validates cited evidence. |
| Reference pages | [ReferencePageEditor](../../app/src/renderer/src/components/world/ReferencePageEditor.tsx) and [ReferenceCards](../../app/src/renderer/src/components/world/ReferenceCards.tsx) implement common editors for organizations, world rules, codex, wiki, and notes. [Shared reference config](../../app/src/shared/referencePages.ts) defines fields and allowed link roles. [OrganizationMembers](../../app/src/renderer/src/components/world/OrganizationMembers.tsx) supports character links and names. See the [reference pages main handler](../../app/src/main/ipc/referencePages.ts) for book validation, legacy member data conversion, and writes to `reference_page_details`. |
| Relationships | [RelationshipGraphView](../../app/src/renderer/src/components/world/RelationshipGraphView.tsx) manages draggable SVG nodes and relationship editing. [Relationships IPC](../../app/src/main/ipc/relationships.ts) stores book-scoped links, events and chapter states. [RelationshipIntelligenceTab](../../app/src/renderer/src/components/world/RelationshipIntelligenceTab.tsx) is the related analysis UI. |
| Story timeline | [SidebarTimeline](../../app/src/renderer/src/components/world/SidebarTimeline.tsx) and [CalendarView](../../app/src/renderer/src/components/world/CalendarView.tsx) represent book dates and story-day events. [timelineAnalysis.ts](../../app/src/renderer/src/services/timelineAnalysis.ts) builds inputs from chapter text, staged drafts and context, infers day transitions and supplies a deterministic input key. [Timeline IPC](../../app/src/main/ipc/timeline.ts) saves and reads generated results separately from timeline configuration. |
| Verse timeline | [VerseTimelineView](../../app/src/renderer/src/components/world/VerseTimelineView.tsx) works with separate [verse timeline IPC](../../app/src/main/ipc/verseTimeline.ts) and table. |
| Story Bible | [storyBibleStore](../../app/src/renderer/src/stores/storyBibleStore.ts) maintains lore context and data used by story and writing assistance. [Story Bible IPC](../../app/src/main/ipc/storyBible.ts) provides persisted records and profiles. Memory locks on character/location profile views are UI and AI context state through the workspace, separate from ownership enforcement. |

Cloud sync supports selected base records. Reference-page details, relationship rows, timelines, and most analysis rows are outside granular coverage. See [Database](../Database.md) and [Data and sync](DATA_AND_SYNC.md).
