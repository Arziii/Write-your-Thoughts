# Fantasy map editor

## Entry point and persistence

[BookMaps.tsx](../../app/src/renderer/src/components/world/BookMaps.tsx) manages the selected map, import, location pin UI, and focus editor. [MapCanvas.tsx](../../app/src/renderer/src/components/world/MapCanvas.tsx) owns pan, zoom, fit (re-fitting when toggling focus mode), pointer capture, brush cursor and normalized pointer coordinates. It displays the imported image and interactive pins. Feature points use normalized coordinates and render in a 2560 × 1600 world space. Background images may have another aspect ratio. [Shared map types](../../app/src/shared/maps.ts) define the IPC contract and import size.

[Map IPC](../../app/src/main/ipc/maps.ts) owns map/pin SQLite operations and validates same-book pin targets, normalized coordinates, image type and a 40 MB import limit. It stores imported PNG, JPEG or WebP bytes as separate local files using a temporary write plus rename. [ParchmentMapTools.tsx](../../app/src/renderer/src/components/world/ParchmentMapTools.tsx) stores drawable features under `wyt-parchment-map-<mapId>`, including brushes, optional erasures, paths, stamps and labels. `persist`, `save`, `undo`, and `redo` manage local edits. History is in memory with a 40-step cap. Deleting a layer is distinct from deleting a map. See [Database](../Database.md) before adding cross-device behavior.

## Land Brush and relief

- `startStroke`, `extendStroke`, and `finishStroke` create a draft in the existing pointer pipeline and commit once on release. Intermediate draft updates are batched with animation frames. Water/eraser subtract from the land silhouette. Edge Brush tests proximity to land and water. Shape Brush and polygon tools also contribute geometry.
- Land Brush defaults to Smart Terrain Blending. Optional `brush.blend` stores hardness, blend strength, stable edge noise, color harmonization and relief settings. Opacity, texture scale and rotation are stored alongside the brush. Missing blend settings remain valid. The original SVG texture paths render a scene with no smart strokes.
- The SVG handles the land-area mask, water backdrop and coast relief. [TerrainBlendLayer.tsx](../../app/src/renderer/src/components/world/TerrainBlendLayer.tsx) inserts the blended canvas within that mask. [terrainBlend.ts](../../app/src/renderer/src/components/world/terrainBlend.ts) implements `TerrainCompositor.render`, cache invalidation and CPU tile compositing. It keeps world-aligned RGB samples sharp while calculating a distance-based opacity falloff with deterministic noise. It uses visible underlying layers, keeps matching-material overlaps stable, and applies one combined height-field lighting pass. Tile halos allow continuous gradients. It caches committed tiles and draft distances and redraws dirty regions.
- [seamlessTerrain.ts](../../app/src/renderer/src/components/world/seamlessTerrain.ts) prepares and caches repeating tiles from bundled terrain artwork. For transparent cutouts it finds an opaque area before preparing the repeating tile. The tile aspect ratio is used in both the SVG and Canvas texture paths. [terrainSurface.ts](../../app/src/renderer/src/components/world/terrainSurface.ts) provides deterministic noise and generates legacy terrain color and elevation data. Blended shading uses generated height data where present, otherwise a procedural field. Existing source textures may have lighting baked in. ComfyUI is separate from this pipeline.

## Paths and stamps

[atlasPaths.ts](../../app/src/renderer/src/components/world/atlasPaths.ts) defines splines, settings, feature defaults and terrain classification. [AtlasPathControls.tsx](../../app/src/renderer/src/components/world/AtlasPathControls.tsx) offers point/freehand mode and tool-specific controls through the parent. [AtlasPathLayer.tsx](../../app/src/renderer/src/components/world/AtlasPathLayer.tsx) paints using [atlasPathPaint.ts](../../app/src/renderer/src/components/world/atlasPathPaint.ts). Roads read painted terrain and nearby stamps or a manual texture override. Endpoints can snap to paths and approximate settlement entrances. Rivers interpolate width and fade over water. Bridges are derived from path intersections. Borders support five styles and optional fill. Paths are stored as vectors with settings, with compatibility defaults for earlier features. Imported flat images provide no land-class metadata.

[mapStampAssets.ts](../../app/src/renderer/src/components/world/mapStampAssets.ts) reads the local manifest and Vite PNG URLs for mountains, forests and settlements. [MapStamp.tsx](../../app/src/renderer/src/components/world/MapStamp.tsx) displays, selects and drags PNG stamps. The editor supports placement previews, repeated placement, scale, opacity, rotation, depth ordering, duplicate/delete, and forest scatter within the Forest tool. Pins and labels render above the terrain/path/stamp composition.

Bundled source assets live under [assets/maps](../../assets/maps). The tree has 12 enhanced terrain PNGs, 33 manifest stamps, 9 road strips, 3 river strips, and 4 border PNGs. The road/river renderer consumes local strips, and political borders currently use procedural drawing. The [asset manifest](../../assets/maps/map-assets/map-assets/manifest.json) and [license inventory](../../assets/maps/map-assets/map-assets/LICENSES.md) identify the credited Van der Aa subset. The credits leave additional artwork provenance unspecified. [terrainAssets.ts](../../app/src/renderer/src/components/world/terrainAssets.ts) scans top-level PNG, WebP, JPEG and JPG files, preferring PNG over WebP and JPEG for the same terrain name. Keep an existing filename stem to update that terrain. The current Mossy Ancient Grassland and Isometric Woodland Clearing files keep the saved keys `Seamless Ancient Grassland` and `Lighter, Open Canopy Forest`. Previews use the original artwork, and the brush uses prepared tiles. Restart dev after replacing source art and rebuild for a packaged copy. Keep path PNGs and stamp entries in their existing asset directories and verify offline rendering. See [Testing](../TESTING.md).
