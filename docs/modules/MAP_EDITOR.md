# Fantasy map editor

## Entry point and persistence

[BookMaps.tsx](../../app/src/renderer/src/components/world/map-editor/BookMaps.tsx) manages the selected map, import, location pin UI, and focus editor. [MapCanvas.tsx](../../app/src/renderer/src/components/world/map-editor/MapCanvas.tsx) owns pan (middle-drag, `Space + Drag`, and right-click drag), zoom (`− | % | + | Fit` pill, up to `48×` zoom), fit (re-fitting when toggling focus mode), physical-sheet elevation framing, pointer capture, brush cursor, normalized pointer coordinates, and viewport-anchored overlays (`viewportOverlay` for the live cartographic scale bar). It displays the imported image and interactive pins. Feature points use normalized coordinates and render in a `3840 × 1920` (`2:1` Earth-proportioned) world space. Background images may have another aspect ratio. [Shared map types](../../app/src/shared/maps.ts) define the IPC contract and import size.

[Map IPC](../../app/src/main/ipc/maps.ts) owns map/pin SQLite operations and validates same-book pin targets, normalized coordinates, image type and a 40 MB import limit. It stores imported PNG, JPEG or WebP bytes as separate local files using a temporary write plus rename. [ParchmentMapTools.tsx](../../app/src/renderer/src/components/world/map-editor/ParchmentMapTools.tsx) delegates studio chrome to [MapTopBar.tsx](../../app/src/renderer/src/components/world/map-editor/MapTopBar.tsx), [MapToolRail.tsx](../../app/src/renderer/src/components/world/map-editor/MapToolRail.tsx), a floating active-tool pill (including a quick `Add land / Carve water (X)` toggle when sculpting and live measured distance in `Ruler` mode), and [MapInspector.tsx](../../app/src/renderer/src/components/world/map-editor/MapInspector.tsx) (`Tool` / `Layers` tabs, **Scale Ruler**, `Sculpt land` vs. `Paint biome` mode switch, 4 brush-size preset dots up to `640px`, always-visible biome/water grids, layer thumbnails, and visibility eyes). [mapScale.ts](../../app/src/renderer/src/components/world/map-editor/mapScale.ts) defaults new maps to Earth's equatorial circumference (`40,075 × 20,038 km`), converts `km`/`mi`/`leagues`, calculates point-to-point & multi-waypoint distances, calibrates map scale from any measured line, estimates fantasy travel times (`On foot`, `Wagon`, `Horseback`, `Sailing ship`), computes zoom-responsive scale bar ticks, and persists per-map scale configs under `wyt-parchment-map-scale-<mapId>`. `ParchmentMapTools` binds studio shortcuts (`V`/`R`/`B`/`W`/`E`/`T`/`X`/`[`/`]`/`Backspace`), auto-numbers new layers, and stores drawable features under `wyt-parchment-map-<mapId>`, including brushes, optional erasures, paths, stamps and labels. `persist`, `save`, `undo`, and `redo` manage local edits. History is in memory with a 40-step cap. Deleting a layer is distinct from deleting a map. See [Database](../Database.md) before adding cross-device behavior.

## Land Brush and relief

- `startStroke`, `extendStroke`, and `finishStroke` create a draft in the existing pointer pipeline and commit once on release. Intermediate draft updates are batched with animation frames. `BrushShape` in `ParchmentMapTools.tsx` displaces non-`Fill` coastlines using a zero-mean 4-octave `fractalNoise` SVG `<filter>` driven by `coastDisplacementScale` / `coastDisplacementReach` / `coastTurbulenceFrequency` from `terrainBlend.ts` (`roughness` `0–40`, default `8`; quick presets `Smooth 0`, `Gentle 8`, `Natural 20`, `Rugged 36` in `MapInspector.tsx` across `Sculpt land`, `Carve water`, `Shape brush`, `Edge brush`, and `Water brush`) and supports `'Polygon'` shapes for traced continents and inland lakes. Water/eraser subtract from the land silhouette. Land Brush in **Paint biome** mode sets `brush.clipToLand = true`, clipping strokes strictly inside existing coastlines without altering the land mask or coastal halo. Edge Brush tests proximity to land and water. Shape Brush and polygon tools also contribute geometry.
- Land Brush defaults to Smart Terrain Blending. Optional `brush.blend` stores hardness, blend strength, stable edge noise, color harmonization and relief settings. Opacity, texture scale and rotation are stored alongside the brush. Missing blend settings remain valid. The original SVG texture paths render a scene with no smart strokes.
- The SVG handles the land-area mask, water backdrop and coast relief. [TerrainBlendLayer.tsx](../../app/src/renderer/src/components/world/map-editor/TerrainBlendLayer.tsx) inserts the blended canvas within that mask. [terrainBlend.ts](../../app/src/renderer/src/components/world/map-editor/terrainBlend.ts) implements `TerrainCompositor.render`, cache invalidation and CPU tile compositing (`pattern` uses 4-octave fractal noise aligned with SVG coast reach so displaced peninsulas and carved fjords avoid tan parchment gaps). It keeps world-aligned RGB samples sharp while calculating a distance-based opacity falloff with deterministic noise. It uses visible underlying layers, keeps matching-material overlaps stable, and applies one combined height-field lighting pass. Tile halos allow continuous gradients. It caches committed tiles and draft distances and redraws dirty regions.
- [terrainSurface.ts](../../app/src/renderer/src/components/world/map-editor/terrainSurface.ts) generates the 8 torus-seamless painterly fantasy biomes (`Grassland`, `Plains`, `Woodland`, `Highlands`, `Snow`, `Desert`, `Marsh`, `Ashlands` with sunlit sage-gold grass tufts/stipples wrapped onto `Plains` and dune ripples on `Desert`) via `makeProceduralBiomeTile`, provides legacy name resolution via `resolveTerrainName` so older saved layers still render seamlessly, and builds map-space height relief via `makeTerrainSurface`. [seamlessTerrain.ts](../../app/src/renderer/src/components/world/map-editor/seamlessTerrain.ts) prepares and caches repeating tiles from bundled water cutout artwork (cropping to opaque regions). ComfyUI is separate from this pipeline.

## Paths, stamps, and asset layout

[atlasPaths.ts](../../app/src/renderer/src/components/world/map-editor/atlasPaths.ts) defines splines, settings, feature defaults and terrain classification (`terrainFromName`). [AtlasPathControls.tsx](../../app/src/renderer/src/components/world/map-editor/AtlasPathControls.tsx) offers point/freehand mode and tool-specific controls through the parent. [AtlasPathLayer.tsx](../../app/src/renderer/src/components/world/map-editor/AtlasPathLayer.tsx) paints using [atlasPathPaint.ts](../../app/src/renderer/src/components/world/map-editor/atlasPathPaint.ts). Roads read painted terrain and nearby stamps or a manual texture override. Endpoints can snap to paths and approximate settlement entrances. Rivers interpolate width and fade over water. Bridges are derived from path intersections. Borders support five styles and optional fill. Paths are stored as vectors with settings, with compatibility defaults for earlier features. Imported flat images provide no land-class metadata.

[mapStampAssets.ts](../../app/src/renderer/src/components/world/map-editor/mapStampAssets.ts) reads [manifest.json](../../assets/maps/manifest.json) and Vite PNG URLs for mountains, forests and settlements. [MapStamp.tsx](../../app/src/renderer/src/components/world/map-editor/MapStamp.tsx) displays, selects and drags PNG stamps. The editor supports placement previews, repeated placement, scale, opacity, rotation, depth ordering, duplicate/delete, and forest scatter within the Forest tool. Pins and labels render above the terrain/path/stamp composition.

Bundled source assets live under [assets/maps](../../assets/maps) (`stamps/{mountains,forests,settlements}`, `paths/{roads,rivers,borders}`, `waters/`). The tree contains 33 manifest stamps, 9 road strips, 3 river strips, 4 border PNGs, and 2 painterly water PNGs (`Painterly Deep Blue Water Splash-2` → `Deep Blue Water`, `Painterly Turquoise Water Pool-1` → `Turquoise Water`). The [asset manifest](../../assets/maps/manifest.json) and [license inventory](../../assets/maps/LICENSES.md) identify the credited Van der Aa subset. [terrainAssets.ts](../../app/src/renderer/src/components/world/map-editor/terrainAssets.ts) exposes the 8 procedural biome definitions (`terrainTextures`, `defaultTerrain = 'Grassland'`) plus any PNG/WebP/JPEG files in `waters/` (`waterTextures`). Textured Water brush strokes (`brush.water`, with `brush.eraser` recorded on Eraser strokes) subtract from the land silhouette while rendering tiled feathered water beneath land/relief layers, or can be switched to `Default ocean (carve only)` in [MapInspector.tsx](../../app/src/renderer/src/components/world/map-editor/MapInspector.tsx). Restart dev after adding new water PNGs and rebuild for a packaged copy. Keep path PNGs and stamp entries aligned with `manifest.json` and verify offline rendering. See [Testing](../TESTING.md).

## Draft-to-Map Analyzer & Native Layer Builder

- Accessible via **Draft to Map** in [MapTopBar.tsx](../../app/src/renderer/src/components/world/map-editor/MapTopBar.tsx) and the viewer bar in [ParchmentMapTools.tsx](../../app/src/renderer/src/components/world/map-editor/ParchmentMapTools.tsx), [MapDraftImportModal.tsx](../../app/src/renderer/src/components/world/map-editor/MapDraftImportModal.tsx) provides a 3-step workflow (`Upload → Review Overlay → Generate Editable Map`) with a `High Detail` (default) / `Fast Draft` selector and live progress indicator.
- [mapDraftAnalyzer.ts](../../app/src/renderer/src/components/world/map-editor/mapDraftAnalyzer.ts) automatically selects the best available tier (`Cloud Vision AI + Tracer` → `Local Vision AI + Tracer` → `Built-in Offline Analyzer`) or runs `Offline Only` on demand, preparing `1600px` cloud / `1024px` local payloads and running 2-pass Vision extraction in `High Detail` mode (`Pass 1` macro geography/routes ignoring frame/compass ornaments + `Pass 2` exhaustive ridges/forests/settlements/labels) with automatic offline fallback if Vision AI is unconfigured or rejects image inputs.
- [mapContourTracer.ts](../../app/src/renderer/src/components/world/map-editor/mapContourTracer.ts) runs an async chunked `960px` (`High Detail`) / `420px` (`Fast Draft`) Canvas 2D pipeline (`traceDraftContours`) with separable `O(W·H)` morphological filters, line-sketch vs. colored-draft classification, water/land segmentation, Marching Squares + Douglas-Peucker polygon tracing (up to `32` landmasses, `220` vertices each), inland lake extraction, adaptive-median `28×16` biome belt sampling, strait-safe width-aware river tracing, inland Sobel+contrast mountain/forest/settlement detection, and continental-spine `suggestedStamps` auto-placement.
- [mapDraftBuilder.ts](../../app/src/renderer/src/components/world/map-editor/mapDraftBuilder.ts) converts approved analysis into native editable `MapFeature[]` layers (`'Polygon'` landmasses & carved lakes, `clipToLand` blended biome regions, vector `River`/`Route`/`Border` paths, granular mountain/forest/settlement & auto-placed `Stamp` layers, and `Label` layers) committed in one undoable `save()` action.
